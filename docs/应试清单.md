## 二、时间分配（按江苏选拔赛模块 A：90 分钟 / 50 分）

| 阶段 | 建议用时 | 动作 |
|---|---|---|
| 通读题目 | 3 min | 先把所有小题扫一遍，标出分值，**从分值高的开始做** |
| 数据探索 | 10 min | 形状、类型、缺失、重复、描述统计、分布 |
| 数据清洗 | 20 min | 按小题逐项做，**每做完一项立刻在评分表打勾** |
| 数据可视化 | 10 min | 按要求出图，标题/轴标签/图例写全 |
| 建模 | 25 min | 划分数据 → 选算法 → 训练 → 验证集评估 |
| 调参与优化 | 15 min | 调参 + 评估可视化 |
| 复查 | 7 min | 回看评分表，补齐漏项 |

**铁律：先做完再加精度。** 一道 4 分的建模题没做完，比把某模型精度从 0.85 提到 0.87 划算得多。

## 四、计分点对应的动作清单

竞赛按步骤给分，下面每一项都是独立的 1~2 分，**逐项确认做过**：

### 数据探索

- [ ] `df.shape` / `df.info()` 打印结构
- [ ] `df.head()` 打印前几行
- [ ] `df.describe()` 描述统计
- [ ] `df.dtypes` 检查类型是否合理
- [ ] `df.isna().sum()` 统计缺失
- [ ] `df.duplicated().sum()` 统计重复
- [ ] 类别列 `value_counts()`

### 数据清洗

- [ ] 缺失值：**先说明策略再填**（删除 / 均值 / 中位数 / 分组填充 / 插值）
- [ ] 异常值：**箱线图检测 + IQR 处理**（这两个动作分别计分，都要做）
- [ ] 重复值：去重并**打印删除的行数**（"记录删除的行数得 1 分"）
- [ ] 类型转换：`to_numeric(errors="coerce")` / `to_datetime`
- [ ] 编码/标准化：分类变量编码、数值变量缩放
- [ ] 特征创建：至少造一个新特征

### 可视化

- [ ] 图必须有标题、轴标签、图例
- [ ] 中文不乱码

### 建模

- [ ] **先划分**训练集/验证集/测试集，再训练（顺序错了扣分）
- [ ] 明确说出选这个算法的理由
- [ ] 输出验证集上的评估指标

### 评估与调优

- [ ] 指标选对：回归用 MSE/MAE/R²，分类用准确率/精确率/召回率/F1/ROC
- [ ] 评估结果**可视化**展示
- [ ] 调参有过程、有对比

## 五、常见失分点

| 失分点 | 避免方法 |
|---|---|
| 数据探索直接跳过，上来就建模 | 探索是独立计分项，先做 |
| 只做了异常值处理，没画箱线图 | 两个动作分别计分 |
| 去重了但没打印删除行数 | `print(f"删除 {n} 行")` |
| 先标准化再划分训练测试集 | **先划分，再对训练集 fit、对测试集 transform**（否则数据泄漏） |
| 图上没有标题和轴标签 | 出图三件套：`title` / `xlabel` / `ylabel` |
| 中文显示成方块 | 开头 Cell 设字体 |
| 变量名随手起 `a` `b` `c`，后面自己看不懂 | 用业务语义命名 |
| 一个 Cell 塞 50 行代码 | 一个动作一个 Cell，便于定位和计分 |
| 用 `df[cond]["col"] = x` 赋值 | pandas 3.0 下不生效，**必须用 `.loc`** |
| 忘记保存 / 导出结果文件 | 题目要求"保存处理后的数据"就一定要 `to_csv` |
