### 二·补　`lightgbm` 在 macOS 上还需要 `libomp.dylib`

macOS 的 lightgbm wheel **不自带 OpenMP 运行时**，import 时会报：

```
OSError: dlopen(.../lightgbm/lib/lib_lightgbm.dylib): Library not loaded: @rpath/libomp.dylib
```

本机**没有 homebrew**（`/opt/homebrew/opt/libomp` 不存在，`brew` 也不在 PATH），
所以走 conda-forge 装一份运行时进 `self` 环境（`--no-deps`，不动其他包）：

```bash
/Users/luolinjie/miniconda3/bin/conda install -n self -c conda-forge --no-deps -y llvm-openmp
```

装完 `$CONDA_PREFIX/lib/libomp.dylib` 就位，正好落在 lightgbm `_find_lib_path()` 的搜索路径里。

> 备选：`torch` 自带的 `site-packages/torch/lib/libomp.dylib` 也能用，但要靠 `DYLD_LIBRARY_PATH`，
> 对学生的 notebook 不友好 —— 不采用。

**验证**：

```bash
/Users/luolinjie/miniconda3/envs/self/bin/python -c "import lightgbm; print(lightgbm.__version__)"
```

### 二·补2　⚠️ `lightgbm` 与 `torch` 同进程会 SIGSEGV（OpenMP 冲突）

`lightgbm` 依赖 `libomp`（LLVM OpenMP），`torch` 依赖 `libiomp`（Intel OpenMP）。
macOS/arm64 上两套 OpenMP 同时开多线程会互相踩内存，
**直接段错误杀进程**（`OMP: Error #179: Function pthread_mutex_init failed` 有时都来不及打印）：

```
OMP: Error #179: Function pthread_mutex_init failed
[1]  xxxxx segmentation fault
```

`try/except` **抓不住**（不是 Python 异常，是内核 SIGSEGV），
报错信息也经常看不到 —— 表现就是「跑着跑着 notebook 就断了」。

**修法**：在任何 `import` **之前**把线程数钉成 1，并把 LightGBM 的 `n_jobs` 也设成 1。

```python
import os
os.environ["OMP_NUM_THREADS"] = "1"      # ⚠️ 必须在 import lightgbm / torch 之前

import lightgbm as lgb
import torch

m = lgb.LGBMRegressor(n_jobs=1, ...)     # 双保险
```

> `05_timeseries` 的 `ch08` 与 `final/final_01_load_forecast` 都在 `IMPORTS` 的
> **第一行**放 `os.environ["OMP_NUM_THREADS"] = "1"`，**不要删**。
> 代价是训练略慢（本机全部实测耗时都已按单线程记录），收益是进程不再随机崩。

**验证**：

```bash
/Users/luolinjie/miniconda3/envs/self/bin/python -c "
import os; os.environ['OMP_NUM_THREADS']='1'
import lightgbm, torch
print('ok', lightgbm.__version__, torch.__version__)"
```

### 三·补　`statsmodels 0.15.0` 的 `adfuller` 返回值会变

```python
from statsmodels.tsa.stattools import adfuller
adfuller(x)                    # 0.15：返回普通 tuple，但发 FutureWarning
adfuller(x, result_object=False)   # 显式关掉（0.16 之后将是默认）
adfuller(x, result_object=True)    # 返回 ADFullerResult 对象（.statistic / .pvalue）
```

**0.16（或 2027-07 之后，取较晚者）默认行为会切到 `ADFullerResult`。**
写 ch02 时**显式传 `result_object=...`**，否则 notebook 里会出现满屏 FutureWarning，
且学生升级 statsmodels 后 `res[1]` 这种下标取值会静默取错。
