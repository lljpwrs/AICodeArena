# reading/ —— 读题拆解训练

> 竞赛失分的大头，不是「不会做」，而是「**没看清题**」——
> 漏做小题、理解错口径、该输出的指标没输出。
>
> 这一节练的是**读题**这件事本身，不写代码。

---

## 一、为什么单独练

回想一次没考好的实操：是「写不出来」，还是「写出来了但不是题目要的」？

竞赛题面的特点是**信息密度高、分值埋在小字里**：

- 「统计各列缺失值数量」和「打印缺失值占比」是两件事，各占 2 分；
- 「用箱线图检测异常值」和「用 IQR 处理异常值」是两个独立动作，各占 2 分；
- 「输出验证集结果」——不是测试集，不是训练集。

这些细节，**通读一遍很容易滑过去**。而一旦滑过去，分就没了，且你自己不会发现。

---

## 二、训练法：只填表，不写代码

1. 计时 **5 分钟**读完题面（不许翻资料）。
2. 在一张纸上填这张表——**只填动作，不写代码**：

| 步骤 | 具体动作 | 需要的 API / 方法 | 对应小题 | 分值 |
|---|---|---|---|---|
| | | | | |

3. 填完再展开标准拆解，逐项对：
   - 我**漏了**哪几项？
   - 我的**顺序**对吗（尤其是有依赖关系的步骤）？
   - 我**说得出**要用哪个 API 吗？

> 判据不是「想做对」，而是「**能列出完整清单**」。
> 列不清清单，写代码时必然漏。
