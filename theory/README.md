## 为什么要单独一个目录

竞赛分两块：**理论知识考试**（机考，单选 / 多选 / 判断 / 简答）和**技能操作考试**（上机手撕）。

这两块的复习方式完全不同：

| | 理论考试 | 技能操作 |
|---|---|---|
| 复习方式 | 刷题 + 背概念 | 敲代码 + 比对答案 |
| 记忆载体 | 题面 → 选项 | 代码 → 报错 |
| 组织形式 | 题库（大量短题） | 章节（少量长题） |
| 对应目录 | 本目录 | [`../coding/`](../coding/) |

混在一个目录里会互相干扰，所以物理隔离。

## 已知的考查范围（依据公开赛制）

- **计算机原理**：进制、存储层次、CPU 与内存、操作系统基础
- **数据结构**：线性表、栈队列、树、图、哈希、复杂度分析
- **算法**：排序、查找、递归、动态规划、贪心、二分
- **机器学习与深度学习基础**：监督 / 无监督、损失函数、梯度下降、反向传播、过拟合与正则化
- **模型训练与优化**：数据划分、超参、优化器、训练技巧
- **生成式人工智能系统设计**：大模型基础、Prompt 工程、微调与对齐、RAG、Agent、人机交互流程
- **法律法规与职业道德**：数据安全、隐私保护、算法公平性
